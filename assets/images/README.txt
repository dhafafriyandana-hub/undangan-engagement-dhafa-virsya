TEMPAT FOTO UNDANGAN
Ganti file gambar contoh dengan foto milik sendiri. Gunakan nama file yang sama agar tidak perlu mengubah kode:
- cover.jpg       : foto utama berdua pada halaman pembuka
- pria.jpg        : foto profil mempelai pria
- wanita.jpg      : foto profil mempelai wanita
- galeri-1.jpg s.d. galeri-6.jpg : foto galeri

Disarankan JPG/WebP, rasio foto cover 1:1, ukuran 800-1600px, kompres sebelum upload.
Jika ingin memakai nama file lain, ubah alamatnya di assets/js/config.js.
Folder ini sengaja tidak menyertakan foto contoh berhak cipta.
